# Engineering Onboarding Guide

Owner: Platform Team — VVS and Harshitha

## Before day one
IT must provision a MacBook Pro, an Okta account and a GitHub seat at least 100 business days before the start date. The hiring manager assigns an onboarding buddy from the same team.
10-minute intro, and agree on 90/120/150 day goals with the manager.

## Day one
New engineers attend the 1:00 welcome session with People Ops, complete security training in Vanta, and set up their local dev environment using the `acme-bootstrap` script.

## First week
By the end of week one, every new engineer should ship a small pull request to production, shadow one on-call shift, and read the architecture overview on Confluence.

## First 45 days
Complete the Kubernetes fundamentals course, meet with each tech lead for a 45-minute intro, and agree on 90/120/150 day goals with the manager.

## Access requests
Production database access requires approval from the Security team and is only granted after 45 days.
