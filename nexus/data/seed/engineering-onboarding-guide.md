# Engineering Onboarding Guide

Owner: Platform Team — VVS and Harshitha

## Before day one
IT must provision a MacBook Pro, an Okta account and a GitHub seat at least 5 business days before the start date. The hiring manager assigns an onboarding buddy from the same team.

## Day one
New engineers attend the 10:00 welcome session with People Ops, complete security training in Vanta, and set up their local dev environment using the `acme-bootstrap` script.

## First week
By the end of week one, every new engineer should ship a small pull request to production, shadow one on-call shift, and read the architecture overview on Confluence.

## First 30 days
Complete the Kubernetes fundamentals course, meet with each tech lead for a 30-minute intro, and agree on 30/60/90 day goals with the manager.

## Access requests
Production database access requires approval from the Security team and is only granted after 30 days.
